Common Exclusion Reasons

  • Billing only (no AI) — CPT coding updates, billing guides
  • Review/editorial — Systematic reviews, commentaries
  • Traditional ML (no LLM) — Attention networks, BERT variants
  • Not medical coding — Clinical NLP, disease detection
  • Out of scope — MedDRA, LOINC, ICD-9 only
  • Pre-2020 — Before LLM era

Key Learnings This Week

Learning 1: Data Extraction is Systematic

Each paper must be extracted into a structured table with consistent fields — this ensures comparability and reproducibility.

Learning 2: CPT/HCPCS Gap is Real

Most included papers focus on ICD-10-CM. CPT and HCPCS coverage is limited — confirming the research gap.

Learning 3: LLMs are Promising but Not Ready

Multiple papers show LLMs perform well on frequent codes but struggle with rare codes and modifiers.

Learning 4: RAG + Verification is Key

Papers like "Verification is All You Need" and "RAG-LLM for ED ICD-10-CM" confirm that retrieval + verification improves accuracy.
