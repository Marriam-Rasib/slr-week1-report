CLH Paper: Overview

Code Like Humans (CLH) — a multi-agent framework for medical coding that mirrors the workflow of human medical coders.

Four Sequential Agents:

  1. Evidence Extractor — identifies codeable conditions in clinical notes
  2. Index Navigator — maps snippets to ICD Alphabetical Index terms
  3. Tabular Validator — refines candidates using ICD hierarchy and guidelines
  4. Code Reconciler — finalizes codes with instructional notes

Key Learning 1: Agentic Workflow

Agentic Workflow Mirrors Human Coders

  • CLH decomposes medical coding into four sequential agents
  • This directly corresponds to the Analyze-Locate-Assign-Verify approach used by the UK National Health Service (NHS)
  • Confirms that structuring a coding pipeline around the human coder's actual workflow is a valid and effective strategy

Key Learning 2: Full Label Space

Full ICD-10 Label Space Coverage

  • Prior approaches (e.g., PLM-ICD) restrict label space to ~6K MIMIC codes
  • CLH is the first solution to support the full ICD-10-CM system (~70K codes)
  • Achieved by dynamically retrieving candidates from the ICD Alphabetical Index
  • Highlights the importance of open-set coding at inference time
